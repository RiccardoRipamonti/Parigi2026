## Pubblicazione
1. Crea un nuovo repository su GitHub. [web:206]
2. Carica questi file nella root del repository. GitHub Pages cerca `index.html` come file di ingresso del sito. [web:209]
3. Vai in **Settings > Pages**. [web:206]
4. In **Build and deployment**, scegli **Deploy from a branch**. [web:206]
5. Seleziona il branch `main` e la cartella `/ (root)`, poi salva. [web:206]
6. Attendi la pubblicazione del sito all'indirizzo `https://USERNAME.github.io/NOME-REPOSITORY/` per un project site, oppure `https://USERNAME.github.io/` se il repository è `USERNAME.github.io`. [web:149][web:148]

## Dominio personalizzato
GitHub Pages supporta anche domini personalizzati e HTTPS. La configurazione si gestisce da **Settings > Pages > Custom domain**. [web:208][web:79]
